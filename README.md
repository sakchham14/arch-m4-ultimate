# Arch M4 Ultimate Installer

Automated, hardened Arch Linux ARM64 installer optimized for UTM on Apple Silicon M4.

## Usage

1. Boot UTM VM with Archboot aarch64 ISO.
2. Ensure network is working.
3. Run:

```bash
curl -s https://raw.githubusercontent.com/<YOUR-USERNAME>/arch-m4-ultimate/main/arch-m4-ultimate.sh | bash
